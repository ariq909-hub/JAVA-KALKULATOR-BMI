# Kalkulator BMI JavaFX

Aplikasi desktop sederhana untuk menghitung Body Mass Index (BMI) dan menentukan kategori berat badan.

## Syarat
- Java Development Kit (JDK) 17 atau lebih baru
- Apache Maven 3.x
- Apache NetBeans IDE (disarankan version 21+)

## Cara Menjalankan Aplikasi

1. **Clone Repository**
```bash
git clone [https://github.com/ariq909-hub/JAVA-KALKULATOR-BMI.git](https://github.com/ariq909-hub/JAVA-KALKULATOR-BMI.git)
cd JAVA-KALKULATOR-BMI/KalkulatorBMIJAVA
